# Online Materials Database

**CPSC 490 · Fall 2026 · Group 07 — Mighty Morphins** · **Sponsor:** Edwards Lifesciences (EL-1)

## Project Summary

The Online Materials Database project aims to reduce the time and manual effort required to retrieve material information from Certificates of Conformance (CoCs) and internal material test reports. The proposed workflow accepts supported PDF documents, extracts material identification and mechanical-property information, and flags uncertain results for review. Verified information is stored as structured records in a centralized relational database, with links to source documents. An internal web application will let authorized users search, filter, view, and compare historical material records.
